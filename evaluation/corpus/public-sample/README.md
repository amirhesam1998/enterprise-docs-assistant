# Public / sanitized sample documents

Optional. Documents placed here are **committed**, so they must be public-domain or
fully sanitized — no names, national IDs, account numbers, signatures, secrets, or
other PII (see `docs/benchmark-corpus-plan.md` §G).

This folder is empty by default. Do not add private or real enterprise documents
here — those belong in `../local-private/` (git-ignored). When in doubt, keep the
document local and commit only its manifest entry and labels.
